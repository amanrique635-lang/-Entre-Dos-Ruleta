Cómo agregar una imagen:
1. Sube la imagen a esta carpeta: images/positions/
2. Usa el nombre que aparece arriba, por ejemplo pose-01.webp.
3. Si quieres usar otro nombre o formato, abre app.js y busca "const positionCards".
4. Cambia la propiedad image de esa posición. Ejemplos:
   image:"images/positions/pose-01.webp"
   image:"images/positions/mi-imagen.jpg"
   image:"images/positions/pose-08.png"

Puedes usar WEBP, JPG, JPEG o PNG. WEBP suele pesar menos.

Si una imagen todavía no existe, el juego mostrará un recuadro de referencia en vez de un icono roto.
